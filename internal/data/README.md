# Data Package

## Description
This repository hosts a Private Packages designed to be integrated within GO Core services. These modules provide a range of functionalities that are commonly required across different services(including generic data models and functionnalities...).

## Installation Instructions
Add the module to any GO service by running the following command:
```bash
go get github.com/plsyro/data-pkg @version
```
Or include in go.mod:
```bash
require (
	github.com/plsyro/data-pkg @version
)
```
Then, execute:
```bash
go mod tidy
```
